# Точка невозврата

Статическая страница иллюстрированного рассказа. Текст находится в `story.md`, готовая версия сайта — в `docs/index.html`.

## Публикация на GitHub Pages

1. Закоммитьте и отправьте файлы в ветку `main`.
2. В репозитории откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку **main** и папку **/docs**.
4. Сохраните настройки. Ожидаемый адрес: https://running-idiot.github.io/noreturn/.

Для работы сайта не нужны Python, Node.js или серверная часть. Все пути относительные; страницу можно открыть локально. Сайт работает без внешних шрифтов, библиотек и запросов к сторонним сервисам.

## Обновление рассказа

После редактирования `story.md` пересоберите HTML:

```sh
python -m pip install -r requirements-dev.txt
python scripts/build_site.py
```

Скрипт поддерживает используемую в рассказе разметку: заголовок `#`, главы `###`, абзацы, курсив, полужирный текст и изображения. Новые изображения указывайте относительными путями внутри репозитория.

Оформление — `docs/assets/style.css`; шаблон страницы — `scripts/page.html`; необязательные улучшения навигации — `docs/assets/reader.js`.

Изображения автоматически преобразуются в WebP шириной до 640, 1000 и 1600 пикселей. Браузер выбирает подходящий вариант через `srcset`. Исходные PNG сохраняются в корне и не входят в публикуемую папку `docs`.

## Локальный просмотр

```sh
python -m http.server 8000 --directory docs
```

Откройте http://localhost:8000. После изменений обновите страницу браузера. Завершение сервера — Ctrl+C.
